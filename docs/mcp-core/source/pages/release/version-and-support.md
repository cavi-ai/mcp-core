# Version and support

This documentation is for `cavi-mcp-core` {{PRODUCT_VERSION}}, released as `{{RELEASE_TAG}}` from commit
`{{RELEASE_COMMIT}}`.

Versions come from git tags: `vX.Y.Z` builds `X.Y.Z`. Before 1.0, modules, signatures and result fields
can still change. Every change is recorded in the repository
[CHANGELOG.md](https://github.com/cavi-ai/mcp-core/blob/main/CHANGELOG.md). Until 1.0, security fixes go
to the latest minor release and `main`.

## Package requirements

- Python 3.15 or later.
- The MCP Python SDK 2 and pydantic 2.
- Process supervision and launch registration: Linux or macOS. Process inspection: macOS.
